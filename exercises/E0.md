# E0: Getting Started
## Introduction
Welcome to the Exercises for this module. We recognize that our students come from very diverse backgrounds, so these Exercises are designed using the principle of **differentiated instruction**. Our goal is to provide a suitable challenge for everyone, regardless of their starting point.
### Exercise Structure
Each exercise consists of two main pages:
1. The **Exercise Overview** page (like this one)
    - **Introducton**: An overview of the topic and the necessary background knowledge.
    - **Data**: The dataset for the exercise (if applicable).
    - **Basic Tasks**: The core requirements for all students.
    - **Advanced Tasks**: Recommended extra tasks.
    - **Assignment Submission**: The requirements for your assignment submission (if applicable).
    - **Further Reading**: Further discussions on the topic and additional resources.
2. The **Lesson** page (e.g., [Lesson 0](lessons/E0.md))
It provides a complete, step-by-step guide for completing the **Basic Tasks**.
### User Manual
For students with different skill levels in ArcGIS Pro, we recommend the following study strategies.

After reading the Exercise Overview page, check your familiarity with each Basic Task:
- **If you are new to these tasks:**
    Follow the Lesson page instructions carefully. The Advanced Tasks can be skipped if you find them too challenging. Your main goal is to understand the fundamental workflow.
- **If you have an idea of the workflow but cannot reproduce it:**
    Use the Lesson page instructions to pinpoint and strengthen your weak areas. Once you can complete the Basic Tasks confidently, you should then proceed to the Advanced Tasks. This is common if you:
    - **Need to refresh your memory**: Use the Lesson page to recall specific steps or tools.
    - **Are switching from ArcGIS Desktop (ArcMap)**: Focus on learning the new ribbon interface and updated workflows.
    - **Are coming from QGIS or other GIS software**: Use the Lesson page to learn ArcGIS Pro's specific tools and terminology.
    - **Are new to the English interface**: Following the steps will help you become familiar with the terms.
    - **Are self-taught**: Use this as an opportunity to align your methods with a standard workflow.
- **If you can reproduce the workflow without checking the Lesson page:**
    Challenge yourself. After confirming you can complete the Basic Tasks, move on to the Advanced Tasks. For an additional challenge, try to achieve the same results for the Basic Tasks using QGIS.
### Exercise Platform: ArcGIS Pro
In most Exercises, we will work with ArcGIS Pro, which is the dominant commercial Geographic Information System (GIS) software in the world. You are provided with the campus license by TUM. Considering its standardized workflow and stable performance, it is selected as the software for the Exercises. **You are required to complete the Exercises using ArcGIS Pro.**

Of course, we firmly embrace Open Science and Open Source Software. [QGIS](https://qgis.org/) is a powerful, free alternative that has a large and active global community. If you already have sufficient experience with ArcGIS Pro, you are encouraged to complete the Exercises with QGIS. (Please consult with the instructor before you do so.) We will also discuss **QGIS and Open Source GIS** in [E10](E10.md).

Read more about [Common Platform for GIS Tasks](#common-platforms-for-gis-tasks).

## Further Reading
### Common Platforms for GIS Tasks
Different GIS tasks require different platforms. For example, imagine you need to:
- **Route Optimization**: Plan the safest, greenest, and flattest route for a city-wide cycling event.
- **Change Detection**: Watch satellite images to see how a newly-built park turns from brown to vibrant green over a few months.
- **Collaborative Mapping**: Build a map for your favorite hiking trails, letting friends leave geotagged comments and upload photos.
- **Urban Planning**: Track population movement to help decide where to build new schools, hospitals, or public transport lines.
- **Crowd Analytics**: Analyze mobile phone data to understand how people move through the city during a festival to optimize bus schedules.

To tackle challenges like these, here are the most common types of platforms:
1. **Desktop GIS Software**: Powerful, all-in-one applications for analysis, visualization, and cartography.
    - Commercial: [ArcGIS Pro](https://www.esri.com/en-us/arcgis/products/arcgis-pro/overview)
    - Open Source: [QGIS](https://qgis.org/)
2. **Programming & Scripting**: Using code to automate workflows and perform custom analysis, typically with Python libraries like [ArcPy](https://pro.arcgis.com/en/pro-app/arcpy/main/arcpy-a-python-package.htm), [Shapely](https://shapely.readthedocs.io/), [GeoPandas](https://geopandas.org/).
3. **Web GIS & Mapping**: Building interactive maps and applications for web browsers using libraries like [OpenLayers](https://openlayers.org/) or APIs from providers like [Google Maps](https://developers.google.com/maps).
4. **Custom Application Development**: Creating highly specialized tools by extending existing software (e.g., via the [ArcGIS Pro SDK](https://pro.arcgis.com/en/pro-app/latest/sdk/)) or building applications from the ground up (e.g., with [GDAL](https://gdal.org/en/stable/)).
